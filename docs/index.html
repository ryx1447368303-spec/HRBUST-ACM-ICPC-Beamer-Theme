字体自动加载

直接读取仓库字体；精简包自动回退到 Fandol，无须手动安装。

使用方法

  1. 编辑 template.tex 中的标题、汇报人和正文。
  2. 运行 latexmk template.tex，或在 PowerShell 7 中运行 .\build.ps1。
  3. 用 .\pack-overleaf.ps1 生成精简包，上传 Overleaf 后选择 XeLaTeX。
